# ⛈️ Storm Chaser 3D

An immersive interactive weather game where you pilot a storm-chasing vehicle through a dynamic supercell thunderstorm. Built with Three.js and WebGL for mobile and desktop browsers.

## 🎮 Play Now

**[▶ PLAY THE GAME](https://hijbgbjjnjbhn.github.io/storm-chaser-3d/index.html)** | **[📖 Full Documentation](https://hijbgbjjnjbhn.github.io/storm-chaser-3d/)**

No installation needed. Play directly in your browser on iOS, Android, or desktop.

## 🌪️ About the Game

Storm Chaser 3D is a continuous sandbox experience with no winning condition. Drive your vehicle into an ever-changing supercell thunderstorm and experience:

- **Realistic Weather Dynamics** - Lightning, hail, wind speeds, and atmospheric effects
- **Vehicle Management** - Track health, fuel, equipment degradation in real-time
- **Infinite Gameplay** - No levels, no finish line, just endless storm exploration
- **Mobile Optimized** - Touch controls designed for iPhone, iPad, and Android devices
- **3D Graphics** - Built with Three.js for beautiful real-time rendering

### How Long Can You Survive?

Manage limited resources while navigating extreme weather. Lightning strikes deal damage. Hail damages equipment. Fuel is limited. How close can you get to the storm's core?

## 📊 Game Mechanics

### Vehicle Status
| Stat | Description |
|------|-------------|
| **Health** | Decreases from lightning and hail. 0% = Vehicle destroyed |
| **Fuel** | Consumed while driving. 0% = Stranded |
| **Equipment** | Degrades over time. Affects radar and sensor reliability |
| **Wind Speed** | Increases as you approach storm. 100+ mph possible |

### Strategic Gameplay
- Balance risk vs. reward - get closer for more intense experience, but face greater damage
- Manage fuel carefully - you need reserves to escape
- Monitor the radar for storm intensity
- Watch the event log for critical warnings

## 🎯 Game Tips

- 📍 **Watch the radar** - Red rings show danger zones
- ⛽ **Conserve fuel** - You might need it to escape
- ⚡ **Avoid lightning** - If you see lightning strikes nearby, consider retreating
- 🌬️ **Wind increases distance** - Wind speed increases dramatically near the storm core
- 🔧 **Equipment matters** - Keep equipment above 30% for reliable sensors
